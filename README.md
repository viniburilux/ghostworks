# GhostWorks — O Motor de Inteligência Territorial Semântica

> "Não olhe para fotos de satélite. Leia a assinatura matemática do território."

## A História por trás do Código
O monitoramento ambiental tradicional é reativo: ele te diz o que já foi destruído. O **GhostWorks** nasceu para mudar essa lógica. Ele trata o planeta como um espaço vetorial semântico, onde cada pixel de 10 metros conta uma história de 64 dimensões. Criamos este motor para encontrar padrões de impacto — da mineração à degradação de manguezais — antes mesmo que eles se tornem óbvios ao olho humano.

## O que você encontra aqui
*   **A Capacidade:** Um pipeline que ingere embeddings AlphaEarth (Google DeepMind) e transforma séries temporais em índices de transformação territorial (TTI).
*   **O Achado:** O mapeamento inédito da expansão de energia renovável e mineração no Nordeste brasileiro, captado sem supervisão humana.
*   **O Artefato:** O `ghostworks_serializer.py` e o `GlobalExplorer`, ferramentas prontas para traduzir dados complexos de satélite em relatórios interpretáveis por IAs e humanos.

## Para quem este projeto fala
Este repositório é para **gestores de território, mineradoras com compromisso ESG, fundos de transição energética e órgãos de controle** que precisam de uma camada de inteligência que não dorme e não tem viés geográfico.

## Como entrar na conversa
*   **Se você é um pesquisador ou desenvolvedor:** Comece pelo `ghostworks_intelligence_demo.ipynb` para ver como integramos dados do Earth Engine com agentes Gemma.
*   **Se você é um tomador de decisão:** Veja o `images/architecture.png` para entender como nossa infraestrutura de inferência territorial pode blindar sua operação contra riscos invisíveis.
*   **Colaboração:** Estamos refinando a detecção de anomalias. Se você tem dados de *ground truth* ou interesse em validar uma vertical específica, abra uma issue.
