# GhostWorks

**GhostWorks ajuda a tornar transformações territoriais investigáveis.** A página pública explica o motor em três movimentos: ver mudança, comparar padrões e abrir uma pergunta verificável.

> O objetivo não é converter um sinal territorial em veredito automático. É organizar evidência, contexto e trajetórias para que uma pessoa saiba onde olhar melhor.

| Camada | Pergunta |
|---|---|
| Ver | O que mudou no território ao longo do tempo? |
| Comparar | Com o que esse padrão se parece? |
| Investigar | Que fontes, imagens e registros podem responder à próxima pergunta? |

Os outputs publicados no site são materiais históricos e situados. Legendas explicitam o que cada imagem mostra e o que ela **não** pode concluir sozinha.

## GitHub Pages

O repositório é servido diretamente pela raiz da branch `master` em <https://viniburilux.github.io/ghostworks/>. Não há etapa de build: basta atualizar `index.html` e os assets versionados em `images/`.
